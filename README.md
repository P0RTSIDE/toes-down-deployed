# Toes Down

A browser study game in the form of Heads Up. A player holds the phone so teammates can see the card, gives clues out loud, and tilts the phone to score. Up marks the card correct. Down skips it. The up and down arrow keys do the same thing on a desktop.

Live site: [toes-down-deployed.vercel.app](https://toes-down-deployed.vercel.app/).

Included packs cover animals, movies and shows, and sports. A custom deck can be typed in or loaded from a file. The round ends with correct and skipped counts.

## Stack

Next.js 15, React 19, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

```bash
npm run build
npm start
```
